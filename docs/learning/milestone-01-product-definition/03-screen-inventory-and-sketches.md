# 03. Screen inventory and sketches

Milestone: **1. Product definition**

Status: **ready to start; learner inventory and sketches pending**

The [current context](artifacts/02-current-system-context.md) separates the mobile loyalty experience from a public simulated sales-point screen. This step translates the chosen journey into the minimum useful interface structure.

## First small objective

List the essential screens for the customer's mobile web app, giving each one a single purpose. Focus on the phone first; inventory the sales-point view after reviewing that attempt.

Success criterion: another person can explain what each proposed mobile screen lets the customer accomplish and how it contributes to the chosen journey. There is no required screen count.

## Learner artifact

Not started. The learner supplies the screen names and purposes before the tutor proposes layouts. A short list or table is sufficient.
